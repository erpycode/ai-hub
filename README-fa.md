## 🌟 هوش مصنوعی هاب چیه؟

**هوش مصنوعی هاب** یه وب‌اپ تک‌فایل مدرن و زیباست که بهت کمک میکنه بهترین ابزارهای AI رو کشف و مقایسه کنی. چه برنامه‌نویس باشی، چه طراح، چه تولیدکننده محتوا، یا فقط به هوش مصنوعی علاقه‌مند باشی — اینجا چیزی برای تو هست.

> *«اگه نمیدونی از کدوم ابزار AI برای کارت استفاده کنی، اینجا جوابتو پیدا میکنی.»*

## ⚡ امکانات

### 🔍 جستجوی هوشمند
اسم ابزار یا دسته‌بندی رو تایپ کن — نتیجه فوری نشون داده میشه.

### ⚡ راهنمای سریع
۳ تا سوال ساده جواب بده و پیشنهاد شخصی بگیر:
1. کارت چیه؟
2. سطحت چقدره؟
3. بودجه‌ات چقدره؟

### ⚖️ مقایسه ابزارها
روی دکمه ⚖️ هر ابزار کلیک کن تا به لیست مقایسه اضافه بشه:
- **امتیاز کل** (از ۱۰۰)
- **۵ معیار**: سادگی، کیفیت، امکانات، ارزش قیمت، سرعت
- **لیست ویژگی‌ها** کنار هم
- **برنده** مشخص شده

### ⭐ علاقه‌مندی‌ها
روی دکمه ⭐ کلیک کن تا ابزار ذخیره بشه. توی حافظه مرورگر ذخیره میشه — حتی بعد از بستن صفحه باقی میمونه!

### 📚 آموزش نصب
ایجنت‌های حرفه‌ای (Hermes, 9Router, Claude Code, Codex, Aider) آموزش نصب قدم‌به‌قدم دارن با دکمه کپی.

### ⌨️ کلیدهای میانبر

| کلید | عمل |
|:-----|:----|
| `/` | جستجو |
| `Esc` | بستن پنجره‌ها |
| `H` | رفتن به بالا |
| `C` | رفتن به دسته‌بندی‌ها |
| `?` | راهنما |
| `R` | ابزار تصادفی |

### 📤 اشتراک‌گذاری
مقایسه ابزارها رو از طریق Web Share API (موبایل) یا کلیپ‌بورد (دسکتاپ) به اشتراک بذار.
